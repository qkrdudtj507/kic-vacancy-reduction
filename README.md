# 지식산업센터 공실률 최소화 방안
### LH COMPAS | 성남시 지식산업센터 분석 → 하남 교산지구 최적 입지 예측

## 1. 프로젝트 개요

지식산업센터('아파트형 공장')는 최근 공급 과잉으로 심각한 공실률 문제를 겪고 있습니다.
본 프로젝트는 **성남시 지식산업센터 50개소**의 데이터를 기반으로 공실률에 영향을 미치는
요인을 분석하고, 이를 통해 학습한 모델로 **하남 교산 신도시**에 지식산업센터를 신설할 경우
공실률이 가장 낮을 것으로 예상되는 입지를 제안합니다.

- **분석 대상**: 성남시 지식산업센터 56개소 (미완공·이상치 제거 후 50개소 사용)
- **예측 대상**: 하남 교산지구 신규 입지
- **최종 제안 입지**: 샘재입구 사거리 부근 (예상 공실률 0.7)
- **최종 모델 성능**: PCA + RandomForest, test MSE 0.0323

원본 탐색적 분석(Colab 노트북들)을 재사용 가능한 함수/클래스 단위로 리팩토링해
`src/` 아래에 정리했습니다. `notebooks/00_full_pipeline.ipynb`가 그 함수들을
순서대로 호출해 전체 분석 흐름을 보여주는 메인 노트북입니다.

팀원 : 김은서, 박영서, 손세희

## 3. 분석 흐름

```
원본 데이터 로드
     ↓
공실률 산정 (연면적 대비 점유면적, 결측 보간)
     ↓
상가 업종 밀도 + 표제부(승강기/주차장) + 매매가 결합
     ↓
100m 격자 데이터셋 구성 (유동인구·거주인구·카드매출·상권·교통·공시지가)
     ↓
지식산업센터별 buffer 집계 (상권 500m / 인구 100m / 지하철 2000m) + 최근접 거리
     ↓
EDA: 상관관계 히트맵, VIF 다중공선성 확인
     ↓
PCA로 차원 축소 → RandomForest 학습 (test MSE 0.032)
     ↓
동일 파이프라인으로 하남 교산지구 격자 공실률 예측 → 최적 입지 제안
```

## 4. 모델링 과정 요약

여러 방법론을 비교 검토한 뒤 최종 모델을 선정했습니다.

| 방법 | 결과 | 채택 여부 |
|---|---|---|
| 지리가중회귀(GWR) | 표본 50개로 과적합 발생 | ❌ |
| 군집분석 | 군집별 평균 공실률 차이 없음 | ❌ |
| 다중회귀(OLS) | 대부분 변수 유의하지 않음 | ❌ |
| 로지스틱회귀 | 이진분류라 해석 불명확 | ❌ |
| **PCA + RandomForest** | **test MSE 0.032**, 다중공선성 해결 + 변수 해석 가능 | ✅ |

### 주요 인사이트 (PCA 성분별 공실률과의 상관관계)
- PC1(경제·상업 활동) ↑ → 공실 ↓
- PC2(거주 인구) ↑ → 공실 ↓ (약한 관계)
- PC3(부동산 시세) ↑ → 공실 ↑
- PC4(주중 유동인구) ↑ → 공실 ↓

## 5. 결론 및 제언

- 상가 수, 대중교통 접근성, 유동인구가 많을수록 공실률이 낮아지는 경향을 확인했습니다.
- 이를 바탕으로 하남 교산지구 내 상권·교통이 발달한 대로변 인접 지역, 특히 **샘재입구 사거리 부근**을
  최적 입지로 제안했습니다.
- 공실률 감소 방안으로 ①다양한 업종 유치 ②버스·지하철 등 교통편 확충 ③소셜미디어를 통한
  유동인구 유입을 제시했습니다.

## 6. 한계

  실제 값 사이에 차이가 있을 수 있습니다.
